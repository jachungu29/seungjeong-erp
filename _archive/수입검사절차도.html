현재 절차도는 파워포인트 도형+현장사진 플로차트라 자동으로 화면에 옮기기 어렵습니다. 아래처럼 한 번만 이미지로 저장해 주시면 이 화면에 그대로 넣어드립니다.

  1. PPT에서 절차도 슬라이드 열기
  2. 메뉴 파일 → 다른 이름으로 저장 → 파일 형식 PNG (또는 슬라이드 우클릭 → 그림으로 저장)
  3. 파일명 수입검사절차도.png → C:\ERP\seungjeong-erp\ 폴더에 저장
  4. 저장했다고 알려주시면 이 화면에 바로 표시합니다
