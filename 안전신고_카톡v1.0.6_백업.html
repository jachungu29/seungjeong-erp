Supabase DB 연결

모든 데이터는 Supabase에 기본 저장됩니다. 연결 정보를 확인·수정하고 상태를 점검·연결합니다.

연결 정보

Supabase 프로젝트 URL과 anon 키(공개 클라이언트 키, RLS로 보호)를 입력합니다.

연결 방법

  1. Supabase 대시보드 → 프로젝트 → Settings → API에서 Project URL과 anon public 키를 복사해 위에 입력합니다.
  2. Supabase → SQL Editor에서 아래 DDL을 1회 실행해 테이블과 RLS 정책을 생성합니다.
  3. [저장 & 연결]을 누르면 정보가 저장되고 연결을 점검한 뒤 데이터를 동기화합니다. 상단 DB 버튼으로도 언제든 재점검할 수 있습니다.
