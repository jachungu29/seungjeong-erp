📋 승정 기준정보 불러오기

서식집(v11.0)의 승정 실제 기준정보를 현재 ERP의 기존 화면(양식)에 그대로 채워 넣습니다. 버튼을 누르기 전에는 아무것도 바뀌지 않고, 누르면 기존 데이터를 먼저 백업한 뒤 교체합니다.

사용법(3단계)
1️⃣ 미리보기로 들어올 데이터를 확인 → 2️⃣ 불러오기(교체) 클릭(확인창 → 자동 백업 → 반영) → 3️⃣ 해당 현재 화면을 열어 데이터가 들어왔는지 확인.
⚠️ 안전 안내 · 파란색 불러오기 버튼이 있는 5종(품목·사원·고객사·협력사·금형)만 현재 화면에 바로 반영됩니다. 설비·계측기는 현재 ERP 데이터가 더 상세하여 교체하지 않고 미리보기·CSV만 제공합니다. 모든 불러오기는 실행 직전 기존 값을 JSON 파일로 자동 다운로드하고 브라우저에도 백업본을 남깁니다.
