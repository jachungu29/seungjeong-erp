처음 한 번 할 일 (PC마다)

  1. Docker Desktop에서 Supabase가 실행 중인지 확인합니다.
  2. Supabase 관리화면(Studio) → SQL Editor에 tools/supabase-setup.sql 내용을 붙여 넣고 Run을 누릅니다. (여러 번 실행해도 안전)
  3. 연결 전에 이 PC 백업: tools\브라우저백업.bat를 더블클릭합니다. 어느 PC를 원본으로 할지는 사장님이 정하고, 원본 PC를 먼저 연결합니다. (연결되면 구조도·불량관리·영업·품질 화면은 DB 값이 이 PC 값을 덮어쓸 수 있습니다)
  4. 위 칸에 서버 주소와 anon 키를 넣고 저장 → 연결 시험이 초록색이면 끝.
  5. ERP를 새로고침(Ctrl+F5)합니다.
