● 연결 확인 중 불러오는 중…

📘 사용설명 · 긴급수주 수용판단 하는 법

  1. 긴급수주 입력 — ＋ 신규 요청 → 품번 선택 시 거래처·공정·품명·단가 자동. 긴급수량·요청납기·UPH(시간당 생산량)를 입력합니다.
  2. 생산능력 입력 — 일 가동시간(예: 2교대 20h)과 잔여 가동률(%)(그 설비가 현재 비어있는 비율)을 넣습니다.
  3. 자동 판단 — 필요시간·가용시간을 계산해 판정이 자동으로 나옵니다: 수용가능 조건부(잔업·금형) 불가(CAPA초과·자재부족·납기경과)
  4. 자재·금형 확인 — 자재 부족이면 즉시 불가(긴급발주 필요), 금형 점검필요면 조건부로 표시됩니다.
  5. 권장조치 참고 — 잔업 필요시간·외주 검토 등 다음 행동이 자동 안내됩니다. 💾 저장·🖨️ 인쇄(대표이사 보고서).
▶ 판단 공식   필요시간(h) = 긴급수량 ÷ UPH  ·  가용시간(h) = 남은일수(납기−오늘) × 일가동시간 × 잔여가동률
▶ 판정 기준 : 가용 ≥ 필요 → 수용가능 / 잔업(최대 +50%)으로 커버 가능 → 조건부 / 그 외 → 불가.   자재 부족·납기 경과는 즉시 불가, 금형 점검필요는 조건부.  ※ 가용일수는 달력일 기준(주말·공휴일 있으면 잔여율로 보정)
