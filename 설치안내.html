승정 ERP 다중 PC 설치·사용 안내

📌 핵심 개념 — 설치할 프로그램이 없습니다
승정 ERP는 웹 + 클라우드 방식입니다. 각 PC는 같은 인터넷 주소만 열면 되고, 같은 클라우드 데이터를 실시간으로 함께 씁니다. 대수 제한 없이 동시 사용 가능합니다.
PC1(사무실) ┐ PC2(집) ├─→ 같은 주소 ─→ 같은 클라우드 데이터 (실시간 공유) PC3(현장) ┘
1단계 · 딱 한 번

인터넷에 올리기 (Push)

담당: 대표님(또는 관리자) · PC 1대에서만
  1. GitHub Desktop 실행
  2. 왼쪽에 바뀐 파일 목록이 보이면, 아래 Summary 칸에 아무 제목(예: 업데이트) 입력
  3. Commit to master 클릭 → 위쪽 Push origin 클릭
  4. 1~2분 기다리면 인터넷 주소에 반영됨
※ 화면·메뉴를 바꾼 뒤에는 항상 이 Push를 해야 다른 PC에 반영됩니다.
2단계 · PC마다 한 번

바탕화면에 실행 아이콘 만들기

담당: 각 PC 사용자 · 처음 한 번만
방법 A · 추천

브라우저로 "앱처럼" 설치

  1. 크롬으로 열기: jachungu29.github.io/seungjeong-erp/index2.html
  2. 우측 상단 ⋮ 메뉴 → 저장 및 공유 → 바로가기 만들기
  3. 이름 승정 ERP → "창으로 열기" 체크 → 만들기
  4. 바탕화면에 승정 로고 아이콘 생성 → 주소창 없는 앱 창으로 열림
엣지: ⋯ → 앱 → 이 사이트를 앱으로 설치
방법 B

실행파일(.url) 복사

  1. 담당자가 준 「승정 ERP.url」 파일과 「승정.ico」를 받음(USB·카톡·메일)
  2. 두 파일을 그 PC 바탕화면에 붙여넣기
  3. 더블클릭하면 실행 (아이콘은 승정 로고)
※ 아이콘까지 보이게 하려면 .ico도 같이 두세요. 간단히는 방법 A가 더 좋습니다.
3단계 · 매일 사용

더블클릭해서 함께 쓰기

담당: 전 직원
  • 바탕화면 승정 ERP 아이콘 더블클릭 → 바로 실행
  • 여러 PC에서 동시에 열어 사용 가능
  • 한 PC에서 저장 → 다른 PC는 새로고침(F5) 하면 최신 반영
✅ 화면 위쪽에 "클라우드 연결됨 ✓"(초록) 이 보이면 정상입니다. 데이터 저장 후 새로고침해서 그대로 있으면 완료.
⚠️ 꼭 지킬 것
  • 인터넷 주소로만 여세요. 컴퓨터 안의 파일(파일 더블클릭)로 열면 저장이 안 되거나 옛 버전이 열립니다.
  • 주소 끝에 점(.)·공백이 붙지 않게 하세요. (404 원인) → 헷갈리면 jachungu29.github.io/seungjeong-erp/ 로 여세요(항상 열림).
  • 화면을 바꾼 뒤에는 담당자가 1단계 Push를 해야 모두에게 반영됩니다.
