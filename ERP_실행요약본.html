ERP 실행 요약본 (Executive Brief)

150페이지 완간 전, 「지금 당장 결정·착수할 것」 1장 요약 · 2026-07-18

현재 위치 (한 줄)

승정 ERP는 이미 GitHub Pages + Supabase 클라우드 하이브리드로 이행(1단계 완료)했다. 54개 화면·21개 대분류가 전 PC 실시간 공유된다. 남은 과제는 보안·경량화·고도화다.

지금 가장 급한 것 3

① 보안 (즉시)
익명 키로 전 데이터 삭제 가능 확인됨. 삭제 차단 + 매일 백업 + 민감정보 분리부터.
② 저장소 경량화
저장소 2.4GB(PDF 445MB+legacy 50MB+이력). 대용량은 NAS로 분리, 링크만 유지.
③ 진단 갱신
보고서 As-Is가 "localStorage 단독"으로 오진. 실측표로 교체 필요.

단계별 착수 (9건)

시점할 일담당
즉시Supabase RLS에서 익명 삭제 차단 (앱 영향 거의 없음)생산기술부
즉시app_state 매일 자동 백업(JSON, 3-2-1)생산기술부

단기민감정보 분리(외국인·사진) + 보존기간 규정관리부
단기대용량 PDF·이미지 NAS 분리 + 링크화(저장소 <1GB)생산기술부
단기사내 공용 접근 게이트(공용PIN 또는 Auth)생산기술부
