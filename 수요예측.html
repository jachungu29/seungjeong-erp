📈 수요예측(포캐스트)

● 연결 확인 중 불러오는 중…

📘 사용설명 · 수요예측(포캐스트) 하는 법

  1. 기준월 설정 — 위 기준월을 정하면, 왼쪽 최근 3개월 실적(직전 3개월)과 오른쪽 예측 3개월(기준월·+1·+2)의 월 이름이 자동으로 맞춰집니다.
  2. 최근 실적 입력 — 각 품번의 직전 3개월 수주(또는 납품) 수량을 입력합니다. (수량이 예측의 근거가 됩니다)
  3. 예측방법 선택 — 품목 특성에 맞게 고르면 예측값이 자동 계산됩니다. (아래 방법 설명 참고)
  4. 고객 내시 반영 — 고객사가 준 발주예정(내시)이 있으면 방법을 「고객내시」로 두고 예측칸에 직접 입력하세요. (자동차 부품은 이게 1순위 기준)
  5. 저장·인쇄 — 💾 저장 시 전 PC 공유, 🖨️ 인쇄로 대표이사 보고서 출력. 예측금액 = 기준월 예측수량 × 단가 자동계산.
▶ 예측방법(자동계산 공식)   가중평균 = (전월×3 + 2개월전×2 + 3개월전×1) ÷ 6 (최근 실적 비중↑, 기본 권장)  ·  단순평균 = 3개월 합 ÷ 3  ·  성장추세 = 전월 + 월별 증감폭 반영(상승/하락 추세)  ·  고객내시 = 고객이 준 예정수량 직접 입력
▶ 자동차 부품 수요예측 순서 : ①고객 내시 확인(1순위) → ②최근 3~6개월 실적 이동평균으로 기준선 → ③신차 양산·단종/계절성으로 보정 → ④결품 방지 여유율 고려 → ⑤매월 예측 vs 실적 비교로 정확도 점검·방법 조정
